# DPI Trust Framework for Agentic AI

An academic software project exploring a digital public infrastructure trust framework for secure, accountable, and trusted agentic AI systems.

## Planned Core Modules

- Agent Identity
- Verifiable Credentials
- Delegation and Authority
- Authentication and Authorization
- Audit and Evidence
- Trust and Risk Evaluation

## Planned Technology Stack

- React
- FastAPI
- PostgreSQL
- Docker
- Open Policy Agent
- W3C DID/VC standards
- Blockchain infrastructure (final technology to be confirmed)

## Project Status

This repository is an initial project setup. The architecture and technology choices are subject to refinement, and some technologies may change during architecture finalization.
